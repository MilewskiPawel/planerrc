# planer  rc

Aplikacja do zarządzania porządkami i harmonogramami (Planer RC).

## Opis
PlanerRC to webowa aplikacja do planowania i organizowania zadań oraz harmonogramów. Aplikacja umożliwia:
- Tworzenie i zarządzanie planami
- Organizowanie zadań i harmonogramów
- Śledzenie postępu prac

## Technologia
- Docker container z obrazem `nightec/planer-rc:latest`
- Uruchamiana na porcie 8124
- Wymaga maksymalnie 50MB RAM i 0,2 CPU
- Automatycznie restartuje się w razie awarii

## Użytkowanie
Aplikacja jest dostępna pod adresem: `http://localhost:8124`
